## Code of Conduct

All contributors and users must adhere to principles of academic integrity, respect, and honesty.

## Reporting Issues

If you discover:
- **Errors or inaccuracies**: Please report with specific line/section references
- **Missing citations**: Notify if sources are not properly attributed
- **Data integrity issues**: Report with verification methods
- **Technical problems**: Describe the issue and environment details

### How to Report

1. Check [existing issues](https://github.com/gimikai92-lgtm/Quantum-Casimir-Energy-Harvesting-and-Entanglement-thesis/issues) first
2. Create a detailed issue with:
   - Clear description of the problem
   - Specific document/chapter/section references
   - Steps to reproduce (if applicable)
   - Expected vs. actual behavior
