# Code of Conduct

## Our Commitment

This research project is committed to maintaining an environment of academic integrity, respect, and intellectual honesty. All participants—whether researchers, collaborators, or users—must adhere to the highest standards of scholarly conduct.

## Scope

This Code of Conduct applies to:
- All interactions regarding this thesis
- Use of thesis content and materials
- Collaboration and communication
- Public discussions and citations
- Implementation of research findings

## Expected Behavior

### Academic Integrity

✓ **Do**:
- Cite sources accurately and completely
- Attribute ideas and work appropriately
- Report findings honestly and accurately
- Acknowledge uncertainties and limitations
- Support reproducibility through transparency

✗ **Don't**:
- Plagiarize or misrepresent work
- Fabricate or falsify data
- Claim authorship incorrectly
- Hide conflicts of interest
- Manipulate results or cherry-pick data

### Respectful Collaboration

✓ **Do**:
- Engage constructively in discussions
- Give credit where it is due
- Acknowledge opposing viewpoints respectfully
- Support diversity in academic thought
- Promote inclusive scholarly environment

✗ **Don't**:
- Use derogatory or offensive language
- Dismiss contributions without engagement
- Discriminate based on identity or background
- Engage in harassment or bullying
- Undermine others' intellectual contributions

### Compliance with Licensing

✓ **Do**:
- Follow license terms (AGPL-3.0 / CC BY-NC-ND 4.0)
- Provide proper attribution
- Disclose source code for AGPL-3.0 derivatives
- Respect commercial use restrictions
- Contact author for permission when required

✗ **Don't**:
- Violate licensing terms
- Use commercially without permission
- Remove or alter copyright notices
- Misrepresent license compatibility
- Claim rights you don't have

## Reporting Violations

If you witness a violation of this Code of Conduct:

1. **Document** the specific behavior and context
2. **Gather** relevant details (date, participants, communication)
3. **Report** to the author: [author.email@institution.edu]
4. **Follow up** on investigation status

### What to Include in Reports

- Clear description of the violation
- Relevant documentation or evidence
- Participants involved (if appropriate)
- Impact and context
- Suggested resolution (optional)

## Consequences

Violations of this Code of Conduct may result in:
- Request for correction or apology
- Restriction from access or collaboration
- Public notice of violation
- Formal institutional actions
- Legal action (for serious breaches)

## Special Considerations

### For Researchers Using This Work

- Maintain confidentiality where appropriate
- Report errors or concerns promptly
- Share improvements and corrections
- Support reproducibility efforts
- Acknowledge limitations in applications

### For Commercial Users

- Obtain proper licensing first
- Comply with all license terms
- Provide transparent attribution
- Respect patent protections
- Report any patent infringement attempts

### For Educational Use

- Ensure proper student attribution
- Maintain academic integrity standards
- Support learning through honesty
- Encourage critical evaluation
- Model ethical scholarship
